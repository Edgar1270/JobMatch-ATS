# 🎯 JobMatch ATS

**Seu currículo mais preparado para a vaga certa.**

JobMatch ATS é um analisador inteligente de currículos. Você compara seu currículo com a descrição de uma vaga, descobre quais palavras-chave estão faltando e gera uma versão otimizada para sistemas ATS (*Applicant Tracking Systems*) — **sem inventar nada**.

> ⚠️ O JobMatch ATS melhora a apresentação do seu currículo com base nas informações fornecidas. Não inventamos experiências ou qualificações e não garantimos aprovação em processos seletivos.

---

## ✨ Funcionalidades

- **Comparação currículo × vaga**: cole a descrição da vaga e o seu currículo para analisar a compatibilidade.
- **Pontuação estimada** de compatibilidade com a vaga.
- **Palavras-chave e requisitos**: veja o que a vaga pede e o que está faltando no seu currículo.
- **Currículo otimizado para ATS**: gere uma versão revisada a partir das suas próprias informações.
- **Exportação em PDF**: revise o resultado e baixe o currículo pronto.
- **Privacidade**: seus textos não são armazenados.

## 🚀 Como funciona

| Passo | O que fazer | Resultado |
|-------|-------------|-----------|
| **1. Cole a vaga e o currículo** | Informe requisitos, responsabilidades e suas experiências, formação, habilidades e qualificações. | Os dois textos prontos para análise. |
| **2. Veja a compatibilidade** | Clique em **Analisar compatibilidade**. | Pontuação estimada, palavras-chave e requisitos. |
| **3. Gere e exporte** | Revise o currículo otimizado. | Download em PDF. |

## 💻 Rodando localmente

Você precisa do [Node.js](https://nodejs.org) e do npm (recomendado instalar com o [nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
# Clone o repositório
git clone <url-do-repositorio>

# Entre na pasta do projeto
cd <nome-do-repositorio>

# Instale as dependências
npm i

# Inicie o servidor de desenvolvimento
npm run dev
```

Depois, abra o endereço exibido no terminal (normalmente `http://localhost:3000` ou similar).
